## English

Personal portfolio website with an RPG/Fantasy theme showcasing my journey as a Junior Full-Stack Developer.

### Features

- **Character Profile** — Hero stats and progression with interactive landing
- **Skills Tree** — Visual skill development (Frontend, Backend, Tools)
- **Missions** — Education, certifications, and quest log with PDF viewer
- **Story** — Personal journey narrative (two chapters)
- **Bestiary** — Technical skills compendium with mastery levels
- **Projects** — Artifact forge showcasing completed and in-progress projects
- **Contact** — Interactive form with Formspree integration
- **🌐 i18n** — Full English/Spanish support with language toggle

### Tech Stack

| Layer | Technologies |
|-------|-------------|
| **Frontend** | React 19, TypeScript, Vite |
| **Styling** | Tailwind CSS v4, Motion (animations) |
| **Icons** | Lucide React |
| **Backend** | Express.js (server-side API) |
| **Testing** | Vitest, Testing Library |
| **Deployment** | GitHub Pages |

### Getting Started

```bash
npm install
npm run dev       # Dev server with API
npm run build     # Production build
npm run lint      # TypeScript check
npm test          # Run tests
npm run preview   # Preview production build
```

### Deployment

Push to `main` → GitHub Actions builds and deploys automatically to:
https://ordinaldragon.github.io/Portafolio/

### Environment Variables

```env
VITE_FORMSPREE_ID=your_formspree_id
```
